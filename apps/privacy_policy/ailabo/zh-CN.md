# 隐私政策（AI LABO）

_最后更新日期：2026年11月19日_

“AI LABO”（以下称“本应用”）是一款让 AI 代表用户操作设备功能的工具类应用。本政策说明本应用会处理哪些信息。

## 1. 本应用的运作方式（订阅与自己的 API 密钥）

本应用提供两种使用方式：

- 应用提供的 AI 模型（订阅制，默认方式）：登录（见第4条）并订阅后，您无需自行获取 API 密钥即可使用开发者提供的 AI 模型。在此方式下，您的聊天内容以及第3条所述 AI 功能的数据，会通过开发者运营的后端服务器（运行于 Google Cloud Run）发送给 OpenRouter。
- 自己的 API 密钥（BYOK，自带密钥，可在高级模式中使用）：您可在设置中输入自己的 API 密钥，可选择 OpenRouter、Anthropic（Claude）、OpenAI（ChatGPT）、Google（Gemini）或 xAI（Grok）。此方式无需登录，请求从您的设备直接发送给服务商，不会经过开发者运营的任何服务器。使用 OpenRouter 密钥时，本应用还会向 OpenRouter 发送一个在您设备上生成的随机标识符（与您的账号无关），以便连续的请求发往同一服务商并复用其提示缓存。

## 2. API 密钥的处理（BYOK 模式）

在 BYOK 模式下输入的 API 密钥仅保存在设备内的加密存储中（iOS Keychain / Android Keystore，通过 flutter_secure_storage）。不会发送给开发者或任何其他第三方。

## 3. 发送到设备之外的信息

### AI 服务商

使用聊天功能时，您输入的消息、附加的图片和文件，以及 AI 执行工具后得到的结果（例如它拍摄的照片、读取的文件或网页文字、您的位置信息、查到的日历日程和联系人）会发送给 AI 服务商，以便 AI 作答。部分 AI 功能还会发送：

- 图片生成与照片编辑：提示词，以及编辑时您或 AI 选择的参考照片。
- 视频生成：提示词，以及用作首帧或尾帧的照片。
- 录音转文字：要转写的音频文件。
- AI 的记忆：AI 存入或检索记忆的文字，会由 AI 服务商转换为数值向量（嵌入）。记忆本身只保存在您的设备上。

使用自己的 API 密钥时，这些信息直接发送给您选择的服务商（录音转文字和视频生成仅在使用 OpenRouter 密钥时可用）；使用订阅时，信息经由开发者的后端服务器发送给 OpenRouter，后端只负责转发这些内容，不会保存（后端保存的内容见第4条）。信息的处理方式遵循实际处理该信息的服务商自身的隐私政策：

- OpenRouter：<https://openrouter.ai/privacy>
- Anthropic（Claude）：<https://www.anthropic.com/legal/privacy>
- OpenAI（ChatGPT）：<https://openai.com/policies/privacy-policy>
- Google（Gemini）：<https://policies.google.com/privacy>
- xAI（Grok）：<https://x.ai/legal/privacy-policy>

本应用会在首次启动时展示同意画面，征求您对此项信息发送的同意。

### 本应用直接连接的网站与服务

- 网络搜索：搜索关键词会从您的设备直接发送给 DuckDuckGo（<https://duckduckgo.com/privacy>），没有结果时会发送给 Wikipedia（Wikimedia Foundation，<https://foundation.wikimedia.org/wiki/Policy:Privacy_policy>）。发送的仅为搜索关键词（以及任何网络请求都会附带的 IP 地址等技术信息）。
- 读取网页与调用网络 API：当 AI 读取网页或发送网络请求（类似 curl 命令）时，您的设备会直接连接 AI 选择的网站并发送请求的内容；如果 AI 上传文件，其中也会包含本应用文件夹中的文件。该网站自身的隐私政策适用。本应用只连接互联网上的公开地址，不会连接您局域网内的设备。
- 地址与地点：查询地址使用操作系统的地理编码服务（iOS 为 Apple，Android 为 Google），搜索附近地点（仅 iOS）使用 Apple 地图。地址或搜索词，以及在您附近搜索时的位置信息，会发送给 Apple 或 Google。
- 语音识别使用操作系统的语音识别服务（Apple / Google），您的语音可能会在它们的服务器上处理。

## 4. 账户与订阅

以下内容仅适用于使用应用提供的 AI 模型的情况。如果您只使用自己的 API 密钥，则不会发生以下任何情况。

- 登录：您可以使用 Google、Apple 或电子邮箱与密码登录（通过 Firebase Authentication）。仅收集您的电子邮箱地址，以及登录方式所签发的标识符。
- 后端服务器：登录后，您的 AI 请求会经过开发者运营的后端服务器（Google Cloud Run，运行于 Google Cloud 基础设施之上），用于确认订阅状态及管理每月使用量（所用 AI 的费用）。后端向 OpenRouter 提供的不是您的账户 ID，而是由它生成的化名 ID。
- 请求记录：对每次 AI 请求，后端只记录其概要：类型（聊天、图片、视频、音频或嵌入）、模型、结果或错误代码、耗时、消息数量、是否包含图片、AI 调用的工具名称，以及 token 数和费用。绝不记录消息、图片、音频和工具结果的内容。这些记录会在 90 天后删除，用于客服支持、排查问题、防止滥用和监控成本。
- 视频生成：为结算视频费用，后端会保存任务 ID、模型、预估费用和时间。生成好的视频只从 OpenRouter 转发到您的设备，不会保存在服务器上。
- 应用验证：为确认请求来自正版的本应用，本应用使用 Firebase App Check（Android 使用 Google Play Integrity，iOS 使用 Apple App Attest）。这会向 Google 或 Apple 发送有关应用和设备完整性的信息，不包含您的内容。
- 订阅管理：购买、恢复购买及订阅状态的确认委托给 RevenueCat（<https://www.revenuecat.com/privacy>）处理。您在 App Store / Google Play 的购买信息会通过 RevenueCat 进行关联。
- 邀请码：当您生成或输入邀请码时，为计算奖励（每月可用量的加成），我们会在服务器上保存邀请方与被邀请方账户之间的对应关系以及您自己的邀请码。邀请方的应用中会针对每位被邀请人显示受邀顺序编号、受邀日期、当前订阅的 AI 套餐（Mini / Standard）及由此带来的加成比例。邮箱地址等可识别任何一方身份的信息绝不会向对方显示。删除账户后，您的邀请码也会被删除。
- 功能投票与提议：当您在“为下一个功能投票”中投票或提议功能时，为执行每天一次的限制并统计票数，我们会在服务器上保存哪个账户在哪天投给了哪个功能，以及您提议的文字内容。提议在公开前会经过审核，并可能以 AI 翻译后的标题显示在列表中（不会显示账户信息）。删除账户后，您的投票和提议记录会被删除（已统计的票数和已公开的标题会保留）。
- 删除账户：在 设置 > 账户与订阅 > 删除账户 中，可以删除您的登录账户，以及服务器为其保存的全部数据（订阅状态、每月用量、请求记录、视频生成记录、邀请码、投票与提议）和您在 RevenueCat 的客户记录。删除账户不会取消订阅，请在 App Store 或 Google Play 设置中取消。如果无法打开本应用，请参阅 <https://normidar.com/ailabo/delete-account.html>。

## 5. 对设备功能的访问

根据您的请求，AI 可以操作以下设备功能：手电筒、振动、语音合成、屏幕亮度、音量（Android）、位置信息与地址查询、方位、气压与步数、蓝牙（扫描，以及从设备读取或向设备写入）、读写 NFC 标签、读取 Wi-Fi/电池/设备信息与传感器、读写剪贴板、相机（照片与视频）、扫描二维码、录音与播放以及录音转文字、语音识别、读取/添加/修改/删除日历日程、搜索与添加联系人、生成图片与视频以及编辑照片、本应用文件夹中的文件（创建、读取〔包括 PDF 和 Office 文档〕、编辑、重命名、复制、搜索、删除）、应用专属数据库、待办清单、AI 的记忆、显示 AI 制作的网页（仅在您的设备上提供给本应用自身）、保存到相册、通过系统分享面板分享内容、打开其他应用/网址/地图/拨号应用/短信应用、设置闹钟与预约任务，以及用选项向您提问。

- 这些操作的结果（照片、录音、视频、文件、数据库、待办清单、AI 的记忆）和聊天记录仅保存在您的设备本地，不会上传到开发者运营的任何服务器；只有在第3条所述的情况下才会离开您的设备（AI 读取或使用时发送给 AI 服务商，或发送给 AI 请求的网站）。
- 您从其他应用分享给本应用的文字和文件，只会放进新对话的输入框（文件会复制到本应用的文件夹）。在您亲自发送之前，不会发送到任何地方。
- 默认情况下，各工具执行时不会在应用内额外弹出确认。您可以在 设置 > 工具权限 中将每个工具单独设置为“需确认”（执行前显示确认画面）或“禁止”（AI 无法执行）。无论如何设置，当对话同时接触过外部内容（例如网页，或二维码、NFC、蓝牙的读取结果）和您的个人数据之后，任何可能把数据发送到设备之外的请求，以及覆盖文件、删除日历日程等无法撤销的操作，本应用都一定会先征求您的确认。此外，首次访问相机、麦克风、位置信息、日历、联系人等功能时，系统自带的权限对话框一定会显示。
- 拨打电话与发送短信仅限于打开拨号应用 / 短信应用并预填内容，实际的拨打或发送操作始终由您本人完成，本应用不会擅自拨打电话或发送短信。
- 位置信息、蓝牙、日历、联系人等信息仅在 AI 按您的指示请求时才会获取，不会在后台持续获取。AI 正在生成回复时，如果您离开本应用，它可能会继续运行一段时间；此时显示的通知只包含处理状态，不包含聊天内容。预约任务只在本应用打开期间执行。

## 6. 数据分析与崩溃报告

本应用使用 Firebase Analytics（使用情况统计，例如使用了哪些功能和工具、模型名称、token 数和错误）和 Firebase Crashlytics（崩溃发生时的错误类型与发生位置）以改进应用功能。这两者都不会接收您的实际内容：聊天正文、工具调用参数（文件内容、位置坐标、搜索关键词等）或 API 密钥。登录期间会附上您的账户 ID（Firebase 的化名标识符，不是电子邮箱地址），以便在为您提供支持时与第4条中的服务器记录对照。您可以随时在 设置 > 发送使用情况数据 中关闭这两项。

## 7. 广告

如果您未订阅、使用自己的 API 密钥，本应用会通过 Google AdMob 展示横幅广告（订阅用户，包括“去广告”套餐，不会看到广告）。在需要征得同意的地区（例如欧洲经济区和英国），会先显示 Google 的同意表单，在您做出选择之前不会加载广告。在 iOS 上，本应用会在展示广告前请求跟踪权限（App Tracking Transparency），仅在您授权后才会展示个性化广告；如果您拒绝，则只会展示非个性化广告。

## 8. 向第三方提供信息

开发者不会向第三方出售您的个人信息。上文第3至7条中提到的向 AI 服务商、DuckDuckGo、Wikipedia、AI 按您的请求连接的网站、Apple 和 Google（地址查询、地图、语音识别、应用验证）、RevenueCat 及 Google（Firebase/AdMob）提供信息，仅限于这些服务运作所必需的范围。

## 9. 儿童隐私

本应用不面向13岁以下儿童。
